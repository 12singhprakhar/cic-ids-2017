# Ultimate Guide for KNN Hyperparameter Tuning with Bayesian Search and Random Search

This project focuses on hyperparameter tuning for K-Nearest Neighbors (KNN) using Bayesian optimization techniques. We will leverage the CIC-IDS-2017 dataset to demonstrate these concepts.

## Project Components
- **Notebook**: The project includes an IPYNB file with all the code for implementing Bayesian search on KNN.
- **Dataset**: We use the CIC-IDS-2017 dataset (link to be added).

## Usage Instructions
1. Clone the repository and open the Jupyter notebook.
2. Follow the steps to load the dataset and run the Bayesian optimization process.

  a. Go to the website - "https://www.unb.ca/cic/datasets/ids-2017.html"
  b. Download the dataset.

3. Unzip the dataset file.
4. Use only machine learning datset for this notebook.
5. Make correction in the path's of the load dataset.
6. Then you are good to go.
